# Codice Fiscale Calculator

Free online tool to calculate, validate and decode an Italian codice fiscale.

## Features
- Calculate codice fiscale
- Validate format and control character
- Decode date of birth, gender and place of birth
- Handle omocodia cases

## Website
https://codicefiscalecalcola.com

## Disclaimer
This tool provides an indicative calculation. Only Agenzia delle Entrate can assign or confirm an official codice fiscale.
